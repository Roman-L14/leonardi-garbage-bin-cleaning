# Leonardi Garbage Bin Cleaning Service

Marketing website for Leonardi Garbage Bin Cleaning Service, serving Ocean Township, NJ (07755) and nearby Monmouth County communities.

## Structure

- `index.html` — all page content/copy
- `styles.css` — colors, layout, responsive rules (brand colors are CSS variables at the top of the file)
- `script.js` — mobile nav toggle + the quote form's text-message behavior
- `assets/` — mascot artwork and favicons

## Editing

Open this folder in [VS Code](https://code.visualstudio.com/), edit the files, then open `index.html` in a browser (or use the "Live Server" extension) to preview.

The business phone number (`2155122205`) appears in several `tel:`/`sms:` links throughout `index.html` — use Find & Replace across the file if it ever changes.

## Deploying

This is a static site with no build step. To publish:

- **GitHub Pages**: Settings → Pages → deploy from the `main` branch, or
- **Netlify Drop**: drag this folder onto [netlify.com/drop](https://app.netlify.com/drop) for an instant URL.
